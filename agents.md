# Islington Partners website 

# Project brief
The aim is to build  a modern looking website to be used to communicate Islington Partners. It will be hosted at islingtonpartners.com where there is already a site but it looks a bit bland and dated. The aim of this project it to copy modern design ideas from OpenAI, Hims and Loop Earplugs and apply it to the copy and website structure already on islingtonpartners.com 

# Visual style
While colour is to be used occassionaly for highligting features, the site should be a white background, with black text and use of greys or blacks as hero or feature backgrounds. Hero callout and feature backgrounds should have rounded corners. 

Buttons should have rounded corners. Primary button background should be black

# Typogrophy 
Fonts should be rounded, san serif, light and semi-bold font weights like the loop ear plugs website. Images can be found in the example images folder.

Fonts like: sofia-pro, Inter, Apple SF, SofiaProWeb, Helvetica, Arial, sans-serif

The site should be basic HTML, CSS and Javascript built with Tailwind CSS. 


# Avoid
- Excessive use of colour
- Borders
- Smaller fonts
